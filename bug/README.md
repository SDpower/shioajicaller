## 概述
此目錄包含了**過去**因 Shioaji API 存在的已知漏洞而創建的臨時解決方案和測試程式碼。這些檔案僅供歷史參考。

## 檔案說明

### SubscribeStocks.py
股票報價訂閱程式，包含以下功能：
- 使用 Shioaji API 進行股票報價訂閱
- 實現優雅的程式退出機制
- 包含錯誤處理和信號捕捉

#### 使用方式
1. 確保已設定環境變數：
   - `API_KEY`: 您的 API 金鑰
   - `SECRET_KEY`: 您的密鑰

2. 安裝相依套件：
   ```bash
   pip install shioaji python-dotenv
   ```

3. 執行程式：
   ```bash
   python SubscribeStocks.py
   ```

#### 歷史問題與臨時方案
- **問題描述**: 舊版 API 無法正確訂閱全市場或特定分類的股票報價。
- **臨時方案**: 此程式碼使用了特殊的合約代碼設定 (`contract.code = "2*"`)，利用 Wildcard 功能來訂閱所有 2 開頭的股票 tick 訊號，以此規避 API 限制。

## 官方修正
官方已在新版 API 中修正此問題，現在已可透過正常方式訂閱報價，無需再使用此處的 Wildcard 技巧。
