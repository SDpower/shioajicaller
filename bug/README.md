# API漏洞直到官方修正

## 概述
此目錄包含了因 Shioaji API 存在的已知漏洞而創建的臨時解決方案和測試程式碼。這些檔案將持續維護直到官方發布正式修正為止。

## 檔案說明

### SubscribeStocks.py
股票報價訂閱程式，包含以下功能：
- 使用 Shioaji API 進行股票報價訂閱
- 實現優雅的程式退出機制
- 包含錯誤處理和信號捕捉

#### 使用方式
1. 確保已設定環境變數：
   - `API_KEY`: 您的 API 金鑰
   - `SECRET_KEY`: 您的密鑰

2. 安裝相依套件：
   ```bash
   pip install shioaji python-dotenv
   ```

3. 執行程式：
   ```bash
   python SubscribeStocks.py
   ```

#### 已知問題
- 此程式碼包含針對當前 API 漏洞的臨時修正
- 使用了特殊的合約代碼設定 (`contract.code = "2*"`) Wildcard 來規避 API 限制 取的所有2開頭股票tick訊號

## 注意事項
- 這些程式碼僅供測試和臨時使用
- 一旦官方發布修正版本，請改用官方建議的實作方式
- 使用前請確保已充分測試並了解風險
